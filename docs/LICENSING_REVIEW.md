# Public licensing review and contributor disclosure

Updated 16 November 2026. Status: unresolved; independent legal review pending.
This notice records a conflict and next actions. It does not select a controlling license, change a license grant, revoke existing permissions, or certify clearance.

## What conflicts
| Source | Published statement |
| --- | --- |

| [CONTRIBUTING.md](../CONTRIBUTING.md), licensing section and checklist | Engine code: CC BY-NC-SA 4.0, commercial permission required. Core narrative and character IP described as proprietary. |

Both the software terms and the creative-content scope need reconciliation. Public repository visibility is not evidence that every item has the same permissions. This notice alone does not resolve those permissions.

## Build-in-public practice during review
Continue public discussion, provenance inventory and scoped review. Do not use this notice as clearance for redistribution, commercial reuse, relicensing or incorporation of disputed material.
Preserve license notices and git history. Record new contributions' authors, sources and agreed terms before accepting rights-dependent changes; do not imply that participation transfers copyright.
Existing third-party terms and agreements remain applicable. Avoid publishing private contracts, signatures, correspondence, personal information or privileged legal advice. Public updates should state decisions and status, with a redacted evidence index where appropriate.
Creative Commons advises against using its licenses for software and explains that existing CC grants are generally irrevocable for compliant recipients. A later documentation edit must not be represented as automatically withdrawing earlier rights.

## Epic Games / Paragon boundary
Dominique describes Paragon as a creative antecedent: “the game we are walking in the ashes of.” Record this as owner-described inspiration, not an Epic partnership, endorsement, transfer of Paragon IP or official continuation.
Loptr Lab's original manga, characters and mythology remain distinct from any licensed Epic assets. Neither this repository's MIT nor CC notices can relicense Epic content.
Epic's current Paragon: Revenant listing describes use in Unreal Engine projects and prohibits using the PARAGON trademark to advertise or name a game. This example is not an audit of every Paragon pack.
Epic's Content License Agreement defines UE-Only content, restricts standalone/source redistribution, and prohibits combinations that impose incompatible license terms on its content. Do not place acquired Epic asset source files in the public repository merely because they were free.
Fab's general Standard License is not proof that a particular legacy Paragon acquisition has those terms: Epic says the acquisition license generally continues to apply.
Actual Paragon asset usage, acquisition dates/licenses, intended engine, public renders/video permissions, distribution packaging and proposed names require an asset-by-asset check. No asset inventory or project clearance is established by this notice. Any proposed public title using “Paragon,” including “Paragon Reborn,” needs separate name/marketing review before adoption.

## What Dominique can prepare now
1. Write the intended permissions by category: generic engine code; rules text; manga/story/characters; artwork/music; studio marks. State whether commercial reuse and fan adaptations are intended. This is a decision brief, not a new license.
2. Assemble a dated private rights register: file/asset, author, original source, first publication, license/version and acquisition record, contributor or commission agreement, known reuse, and gaps. Include Epic/Fab receipts and pack listings when relevant.
3. Preserve relevant commits, releases and existing license notices. Identify outside contributors and third-party material; do not rewrite history.
4. Provide a concrete use list: public code/forks, commercial games, manga/animation, film pitches, merchandise and crowdfunding. Identify the intended engine and which assets would ship or appear in publicity.
5. Request a fixed-scope licensing/chain-of-title review using that packet. Keep a public status/decision record, while retaining confidential documents privately.
6. After the decision and any necessary permissions are established, reconcile the license map, contributor guide/checklist, file exceptions and attribution records together. Verify links and disclosures before a separately authorized merge/release.
