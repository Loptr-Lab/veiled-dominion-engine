# Variant Registry and Boundaries

Variants are documentation-first experiments. Presence here does not grant canonical status, implementation status, commercial permission, or endorsement.

## Directories
- examples: original, reusable models contributors may imitate.
- incubation: original experiments still under design or safety review.
- case-studies: historical or third-party-referencing research retained for provenance.
- External projects are indexed in EXTERNAL_CASES.md and remain in their own repositories.

## Required statuses
Every document must declare status, rules authority, source type, implementation, commercial use, accessibility review, and rights review. The machine-readable index is VARIANT_REGISTRY.yml.

## Start here
1. Read ../VARIANT_CREATION_WORKFLOW.md.
2. Copy VARIANT_TEMPLATE.md.
3. Open a variant proposal issue.
4. Do not implement or merchandise a permission-dependent reference.
5. Do not treat Discord dialogue or a mock store listing as rules authority.

The canonical rules remain docs/design/GDD.md and docs/RULEBOOK_v0.1.
