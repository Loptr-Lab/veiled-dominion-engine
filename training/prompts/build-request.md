# Prompt: build a request

> Draft a preparation document for **[human decision-maker]** using only these confirmed inputs: **[goal, tasks, barriers, capabilities, verified sources]**. Organize it as goal, work tasks, functional barriers, essential capabilities, minimum configuration, preferred configuration, alternatives considered, current quotes, uncertainties, and questions requiring a decision. Do not invent facts, diagnoses, eligibility, authorization, or approval. Mark absent evidence **unverified** and flag every statement that needs human confirmation.
