3. Accessibility requirements

The participant describes functional needs without publishing diagnoses or private records. The plan includes readable scaling and contrast, reduced visual strain, resumable task state, low-memory-burden file handling, clear sequencing, alternate input where needed, and reliable ways to recover after interruption.

Each need is tied to a task and linked to the centralized accessibility guidance, avoiding repeated or inconsistent accommodation text.
