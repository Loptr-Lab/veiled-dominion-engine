# 2. Work tasks

Representative tasks include editing and testing code, organizing project files, producing and reviewing media, documenting decisions and provenance, collaborating through repositories, conducting source-based research, and preparing accessible demonstrations.

The participant distinguishes occasional tasks from sustained workflows and identifies which tasks must run concurrently. That prevents a technology list from being assembled before the work is understood.
