# Funding research

Funding is jurisdiction- and program-specific. Start with the jurisdiction tree, verify the responsible agency, and record the source and verification date. Listing a program never guarantees eligibility, authorization, or payment.

- [United States federal context](./jurisdictions/united-states/federal/README.md)
- [Minnesota—first state implementation](./jurisdictions/united-states/state/minnesota/README.md)
- [Program research template](./program-research-template.md)

For another country, territory, state, province, or locality, copy the research method—not Minnesota's rules. Volatile facts such as deadlines, dollar limits, models, and program rules belong in dated, source-attributed research notes.
