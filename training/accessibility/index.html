Accessibility

Describe barriers without oversharing

Describe the barrier in relation to a task, then identify a capability or accommodation. Share only what is necessary; a diagnosis is not required to explain that text must enlarge without clipping or that an input method causes fatigue.

AreaPlanning questions
Visual accessCan content be perceived through contrast, scale, spacing, and non-color cues?
Screen readersAre controls named, ordered, and operable without visual position?
MagnificationDoes reflow preserve context and prevent horizontal scanning?
Input and motor accessCan tasks be completed with alternate input and reduced precision or repetition?
Cognitive and learning accessCan work be resumed, sequenced, checked, and understood without avoidable memory burden?
