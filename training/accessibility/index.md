# Accessibility

Describe the barrier in relation to a task, then identify a capability or accommodation. Share only what is necessary; a diagnosis is not required to explain that text must enlarge without clipping or that an input method causes fatigue.

| Area | Planning questions |
| --- | --- |
| [Visual access](./visual.md) | Can content be perceived through contrast, scale, spacing, and non-color cues? |
| [Screen readers](./screen-reader.md) | Are controls named, ordered, and operable without visual position? |
| [Magnification](./magnification.md) | Does reflow preserve context and prevent horizontal scanning? |
| [Input and motor access](./input-motor.md) | Can tasks be completed with alternate input and reduced precision or repetition? |
| [Cognitive and learning access](./cognitive-learning.md) | Can work be resumed, sequenced, checked, and understood without avoidable memory burden? |

Reference this section from a career track. Do not duplicate the guidance inside every track.
