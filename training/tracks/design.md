# Design track

## Work tasks

Research, sketch, compose, prototype, review, revise, export, and prepare assets for production or handoff.

## Required capabilities

- Perceivable, scalable interfaces and non-color-only review methods
- Input options suited to precision, repetition, fatigue, and mobility needs
- Enough memory, graphics, display area, and storage for the actual asset sizes and tools
- Export, collaboration, font, and color workflows compatible with intended recipients

## Plan

Test common documents and prototypes at the participant's required scale and input method. Document which requirements are essential for access, which improve efficiency, and which are optional preferences.
