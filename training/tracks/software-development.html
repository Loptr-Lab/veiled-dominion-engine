Software development track

Software development track

Work tasks

Read and edit code, navigate repositories, run builds and tests, debug, review changes, manage versions, communicate decisions, and use documentation.

Required capabilities

  • Editor and terminal access compatible with the participant's input and reading methods
  • Enough memory and compute for the selected toolchain, tests, containers, and local services
  • Reliable version control, backups, and authentication that do not depend on inaccessible prompts
  • Multiple-window or context-switching support without losing task state

Plan

Document minimum and preferred capability levels; do not name a product until the actual language, framework, test workload, collaboration method, and accessibility needs are known. Individually assess whether local builds, cloud development, or a hybrid workflow is appropriate.

Development equipment

Use the development environment and equipment guide to compare local, cloud, and hybrid workflows, accessible peripherals, backup, and minimum versus preferred requirements. Do not assume that one device suits every language, toolchain, or test workload.
